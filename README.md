### Selected projects

**[CodeQuest](https://github.com/YOUR_GITHUB_USERNAME/REPO)** — a web application for learning programming through a game

I built the Vue 3 client. Users sign in and move through the app by role. Students, teachers, and administrators each get their own panel. A Unity WebGL game sits inside the page and saves level results to a REST API.

`Vue 3` `Vite` `Vue Router` `Tailwind CSS` `JavaScript` `Unity WebGL` `REST API`

**[PostuRight](https://github.com/YOUR_GITHUB_USERNAME/REPO)** — an application for monitoring correct posture

I co-designed and implemented the Posture Score algorithm from 6 anatomical landmarks, reviewed biomechanical scoring methods, and used an AI model to detect key body points.

`Python` `Kivy` `YOLOv8` `Hailo-8` `Intel RealSense RGB+D` `Raspberry Pi` `Computer Vision`

**[AsciiFlow](https://github.com/YOUR_GITHUB_USERNAME/REPO)** — turning images and video into an ASCII animation

I designed and implemented the algorithm that recognizes the input (still image, GIF, or video) and turns it into ASCII frames: frame extraction and sampling, mapping pixel brightness to glyphs with different ink coverage, and exporting a sequence with playback timing.

`Java` `ANTLR 4` `ImageIO` `FFmpeg`
